# Sprint Plan - Bantay Baha

## User Stories
1. **Resident:** As a resident, I want to see the current water level and advisories on my phone so that I can decide if I need to evacuate.
2. **Barangay Official:** As a barangay official, I want to view trend analytics of the creek water level so that I can issue early warnings to the community.
3. **Resident:** As a resident, I want to read advisories in Filipino and English so that I can clearly understand the safety instructions.

## Acceptance Criteria
- Current water level is color-coded (Green for Normal, Orange for Alert, Red for Danger).
- Analytics show the average, min, max, and trend (rising/falling/steady).
- Advisory generated displays content in both Filipino and English within 3 sentences.
